# Swamy Sharanam • 41 Day Ayyappa Countdown

🙏 **Swamiye Saranam Ayyappa** 🙏

A beautifully styled, minimalist 41-day devotional countdown and daily progress tracker web application built for the sacred Ayyappa Mandala/Makaravilakku season.

## ✨ Features

- **Live Countdown Timer:** Real-time tracking down to the exact hours, minutes, and seconds leading up to **21 December 2026**.
- **Interactive 41-Day Tracker:** Tap any of the 41 days to mark your vratham progress with checkmarks (`✓`).
- **Local Storage Support:** Your daily ticks are automatically saved in your browser, so your progress isn't lost on refresh.
- **Progress Bar & Stats:** Visual completion percentage and progress counter (`0 / 41 completed`).
- **Quick Navigation:** Handy buttons to instantly jump to today's date or reset ticks if needed.
- **Mobile-Friendly / Responsive:** Optimized for all screen sizes with a rich, immersive dark gold spiritual aesthetic.
